# 🎲 우리 반 자리 뽑기 (Random Seat Allocation)

학생 수와 모둠 수를 입력하면 1번부터 마지막 번호까지 무작위로 섞어 모둠별 자리 배치표로 보여주는 초등·중등 교실 맞춤형 자리 배치 웹 애플리케이션입니다.

배치 순간 번호가 빠르게 돌아가는 롤링 애니메이션과 효과음으로 학생들에게 기대감을 선사하며, 교실 환경에 최적화된 칠판 위치 안내, 전체화면, A4 인쇄, 고화질 이미지 저장 기능을 지원합니다.

---

## ✨ 주요 기능

- 🔒 **개인정보 보호 (번호 전용)**: 학생 이름 없이 번호(`1..N`)로만 공평하게 배치합니다.
- ⚖️ **공평한 모둠 분배**: 학생 수($2 \sim 60$명)와 모둠 수($1 \sim 15$모둠)를 지정하면 Fisher-Yates 셔플 알고리즘으로 균등하게 분배합니다.
- 🎰 **두 가지 애니메이션 모드**:
  - **긴장감 모드 🎲**: 슬롯머신처럼 숫자가 롤링되다가 앞 모둠부터 하나씩 '착!' 소리와 함께 순차 공개됩니다.
  - **빠른 모드 ⚡**: 약 2초간 전체 좌석 번호가 동시에 회전한 뒤 일제히 공개됩니다.
- 🔊 **자체 합성 사운드 (Web Audio API)**:
  - 외부 음원 파일 의존 없이 브라우저 내장 오실레이터로 경쾌한 틱, 확정 차임, 승리 팡파레를 실시간 합성합니다.
  - 사운드 온/오프 토글을 지원합니다.
- 🏫 **교실 맞춤형 UX**:
  - **교실 앞/칠판 안내 배너**: 교실 앞쪽(칠판/교탁) 위치를 시각적으로 표시하여 학생들이 자리를 쉽게 찾을 수 있습니다.
  - **다시 뽑기 & 축하 폭죽(Confetti)**: 뽑기 완료 시 화려한 축하 폭죽이 터지며, 언제든 원클릭으로 다시 섞을 수 있습니다.
  - **전체화면 지원**: 전자칠판이나 대형 TV, 프로젝터에 꽉 찬 화면으로 표시할 수 있습니다.
  - **A4 인쇄 & PNG 다운로드**:
    - **인쇄**: 상하단 컨트롤이 자동 숨김(`@media print`) 처리되고 A4 가로(Landscape) 규격으로 깔끔하게 출력됩니다.
    - **PNG 저장**: 고화질 2배율 이미지로 저장되어 메신저 공유 및 보관이 편리합니다.

## 🛠️ 기술 스택

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Audio Engine**: Web Audio API (합성 사운드)
- **Effects & Export**: canvas-confetti, html-to-image
- **Testing**: Vitest, React Testing Library (102개 단위/통합 테스트 100% 통과)
- **Deployment**: GitHub Actions, GitHub Pages
